# PARDES Play

Fun, educational Torah games (Chassidus, Kabbalah, Chabad, Shulchan Aruch, Talmud, Gemara, and more).

## GitHub Pages

1. Create a new repo on GitHub.
2. Upload all files (keep this folder structure).
3. Settings → Pages → Source: **Deploy from branch** → `main` → `/ (root)`.
4. Open `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## Disclaimer

Educational only — not a source of halachic rulings. Study with your rabbi or teacher.

Texts may link to [Sefaria](https://www.sefaria.org). Question content is curated for learning.
